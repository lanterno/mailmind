How MailMind uses AI
Summaries, importance scores, the daily briefing, drafts, and ask-your-inbox are written by Claude, through the Claude API, when an API key is set; without one, AI is off and nothing is sent. Only the text of the mail being summarized, drafted or asked about is sent to Anthropic; your mailbox itself stays in a database on this machine. Email bodies render inside a locked sandbox that can't run code or phone home.
